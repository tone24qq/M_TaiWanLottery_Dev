# 開發與驗收紀錄

驗證日期：2026-11-03，Asia/Taipei。此修改基於 GitHub `main` 的 `171e8e5`，沒有變更或重新發佈 Codex 雲端環境設定。

## 完成範圍

正式入口只提供賓果三星、四星、五星。已刪除其他彩種的 API／爬蟲／CRUD／ORM 及頁面功能；保留原始資料庫遷移，既有其他彩種資料不會被破壞。可重用的統計、特徵、模型與離線研究程式保留，新正式帳本只由新的因果流程寫入。

原專案存在每天一次的賓果排程、全域關閉 TLS 驗證、無逐期固定預測，以及舊頻率調權使用驗證區間統計的問題。新路徑以官方 API、45 秒輪詢、不可覆寫封存、完整 80 號分數及嚴格逐期驗證替換。PDF 提到的 V11～V16 檔案不在這份 GitHub 主線中，因此沒有直接複製其 import 或重建相同版本號；採納雙排行榜、30／100 期門檻、歷史與實戰分離及背景訓練設計。

| 項目 | 實際行為 |
|---|---|
| 初始資料 | 最近三個台北日曆日；不足時受限向前擴充，回報缺期／錯誤 |

## 自動測試

最終完整指令：`python -m pytest -q` → **70 passed in 15.75s**，沒有跳過測試。測試工具與套件版本見 `validation/tested-environment.json`。

測試包含：

- 官方 API schema、完整分頁、第二頁失敗、抓取期間快照變動、缺期／重複／未來資料拒收、台北時區與跨年。
- 因果 tabular 特徵及 Transformer 序列的當期／未來擾動測試；八模型實際 fit／score／pickle 還原，非空函式。
- 四投票尺度與差異、30／100 門檻、隨機基準、區間、策略選擇只能影響其後預測。
- 真正 SQLite 封存與三期連續流程、重複觸發、對獎冪等、快照隔離、缺期補抓、斷線恢復與重啟。
- 真正 spawn 子程序訓練／推論、重複工作阻止、停止後程序回收、模型損壞降級、線上學習不重複更新。
- 重啟不立即重訓、10,000 期視窗滿後仍可計數新期、停止後不自動重啟、60 秒失敗重試、自訂區間補足前置 100 期。
- 十億筆等價直方圖的有界記憶體計算、累計與連續榜分離、跨年 SQL 分組。
- 真正 PostgreSQL：全套 Alembic 升級、主程序鎖、官方格式資料插入去重、封存／結算／冪等、SQL 排行摘要。使用本機暫存 PostgreSQL（pgserver 0.1.4），未連接或變更已發佈環境的資料庫。

另外通過全模組 import、Python 編譯、Ruff 未定義名稱／語法檢查、JavaScript 語法、`pip check`、`git diff --check`。

## 介面與效能驗證

實際服務的首頁及分析頁，在 1440、390、320 px 寬度均無頁面溢出或 JavaScript 錯誤。號碼／表格可於手機操作，排行表在自身容器捲動。測試涵蓋空資料、錯誤重試、文字注入、三種星數與雙榜頁籤、兩次各約 2 MB 報告每次工作只下載一次。截圖見 `screenshots/`，檢查紀錄位於 `validation/ui-*.json`。

最終服務 50 次本機狀態 HTTP 查詢中位約 **7.84 ms**、P95 **12.05 ms**、最長 **13.37 ms**。這是本機單一使用者測量，不是網際網路延遲或高併發容量保證。600 期測試資料的八模型訓練約 12 秒；該資料只用於測試計算與資源，未用來宣稱預測成效。

## 尚存限制

- 官方 API 沒有可用性／延遲保證；這次實測曾約延遲兩分鐘發布。輪詢 45 秒無法消除上游延遲，若下一期截止前仍未更新則拒絕補封存過期預測。
- 官方目前不提供有效的開獎時間欄位，所以時間依完整當日資料及 07:05～23:55 排程推算；若台彩改排程或 schema，系統會拒收並回報，需更新解析器。
- 自動補抓預設限制 31 天；超出界線或歷史不存在時會回報不足，不產生假資料。自訂區間同樣必須具備目標前至少 100 期。
- 此次驗證包含短時間真實跨期、重啟及受控故障測試，尚未進行數週連續壓力／硬體故障／正式備份恢復演練；沒有宣稱已完成長期 SLA。
- 未直接操作使用者的已發佈部署及正式資料庫。PR 合併後仍需在既有部署流程套用程式與 Alembic 遷移。程式預設單一主程序，需多主機部署時應另外實作領導租約／工作協調。
- 目前提供單機服務而非多人身分驗證產品；公開部署需沿用原有 HTTPS／登入閘道。模型工件含 pickle，只讀取本機受信任程式產生的檔案。
- 八模型 CPU 訓練仍有約 400～500 MiB 的單一工作程序記憶體需求；對極小主機可調低執行緒及訓練視窗。效能數字受硬體與同時工作影響。
