# A／B／C 關聯研究引擎驗收

最終引擎版本 `bingo-associations-2`。此功能新增在第二階段分支上，沒有覆寫尚未合併的 PR #1、舊預測帳本或已發佈雲端環境設定。

## 已接入的流程

受限推論程序共享真實已驗證歷史快照，產生原八模型／四投票、Today／Historical／Hybrid 與 A／B／C。ABC 搜尋失敗會留下明確錯誤，原流程仍可封存，不生成假規則或替代數字。ABC 成功時九列影子候選與正式預測在**同一交易**事前寫入，包含完整 80 號分數、排名、真實理由及規則證據。

官方結果確認後，同一既有結算／研究佇列更新 ABC 命中直方圖、最近 100／300 期榜、規則到期／分數退化診斷與再驗證請求。控制器狀態、事件及處理標記原子保存，重啟可接續；未封存的過期目標不補造，已封存數字不改寫。ABC 不自動取代正式策略，不為製造不同號碼加入隨機擾動。

`GET /api/v1/bingo/associations` 只讀取封存；原5秒狀態更新不重傳整棵規則樹。前端20秒不重疊更新、背景分頁暫停，手機先顯示號碼及最多三句理由，規則證據及完整80號排名可展開。三種星數、ABC實戰期間與原模型排行的操作互不影響。

## 真正計算的內容

| 候選 | 計算 | 沒有確認規則時 |
|---|---|---|
| A | 二元矩陣計算1～20期所有80×80延遲條件計數；同期共現另外描述 | 真實平滑條件頻率、固定時間衰減及確定排序，理由對應已選號碼的實際計數；明示探索 |
| B | 最多16組雙號前因，2～5期後雙／三號後果，有限時間延遲群組關聯 | 已知觸發組合的平滑增益；無觸發時可平分，使用固定號碼平手規則，不造變化 |
| C | 實際當折模型分數／投票權重＋目標日頻率、動能、未開間隔、共現＋獨立確認的觸發規則 | 未確認規則的係數為0，其份額回到真實模型融合；目標新日尚無期數時當日統計為0 |

C 的初始研究配比為模型60%、當日頻率15%、動能10%、間隔5%、共現5%、確認規則5%；沒有確認規則時模型65%。可用模型故障會排除並重整權重，沒有模型時回到真實統計。這是預先設定的影子組合，未宣稱配比已優化或有勝率優勢；模型內部權重沿用當時已結算的實績。

每次最多三種歷史視窗（預設200／500／1000）及32條保留規則。所有視窗共用發現／選擇／最終確認的**全域時間界線**，只有發現的參考長度改變。最終確認標籤不參與任何候選視窗挑選。候選的完整證據歷史與最近推論上下文分別記錄，避免短視窗標示隱藏較早的規則驗證資料。

跨期單號使用0.25基準；同期共現使用19/79條件基準，指定q號的同開機率為C(20,q)/C(80,q)。至少20次觸發、以8個先驗樣本平滑、校正後二項尾端／Wilson區間共同檢查。所有實際掃描的號碼／間隔／群組／視窗納入本次Bonferroni搜尋數；大量探索不能直接標為已確認。

同期共現只能描述已知資料，不能把未來尚未開出的號碼假裝為觸發條件。C只使用通過分離資料確認、且由已知期數實際觸發的跨期規則。文字由真實紀錄產生，不呼叫語言模型。

## 界線與限制

- 真實資料尚未確認有可重複的預測關聯，亦未證明ABC優於隨機。歷史條件頻率、相對信心及Lift不能當成下一期中獎機率。
- 規則計數的二項尾端採公平獨立抽獎假設；重疊序列與持續重跑仍有推論限制。本次多重校正不是無限期反覆監看的永久錯誤率保證，更不是中獎策略證明。未加入昂貴置換搜尋；先保留獨立確認及未來影子成績。
- B是最大兩事件、雙號前因與雙／三號後果的受限時間延遲演算法，不是無限制PrefixSpan；刻意限制搜尋成本，較長序列未實作。
- 開發初版v1已有一筆事前封存，發現跨視窗切分問題後保留原紀錄並將引擎升級v2。v1歷史比較已排除，最終100／300／1000全部以v2及來源SHA重跑。累計實戰版本可稽核，不抹除不利或早期樣本。
- 新引擎增加有限矩陣／規則成本，必須看實測時間與峰值，不能把核心矩陣加速倍率當整套系統倍率。完整回測稽核會占磁碟，需備份／歸檔。
- 本次仍是短期本機官方來源運行，尚未累積數百期多日實戰，也沒有數週SLA或正式部署驗收。程式會保守保留既有正式策略，待足夠事前證據再比較。
