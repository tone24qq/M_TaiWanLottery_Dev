# A／B／C 關聯研究：真實資料與向量計數驗證

此報告為獨立歷史影子模擬，**沒有寫入正式實戰帳本，也沒有將 A／B／C 自動取代原正式策略**。三個區間均未找到通過完整分段確認的可靠預測關聯，不能宣稱關聯能提升中獎機率。

## 實際計算與因果邊界

- 引擎版本 `bingo-associations-2`；真實資料為同一份 1276 期官方快照。逐期僅把目標以前最多 1000 期傳給引擎，最多三個候選視窗、延遲 1～20 期、最多 16 組候選群組及 32 條保留規則。
- A 實際計算單號延遲／同期共現；B 實際計算前置號碼組合與後續號碼組合；C 使用當時凍結的八模型分數及 Shrink 權重，結合當日頻率、動能、間隔、描述性共現，以及獨立確認且當下觸發的規則。
- C 的八模型輸入來自對應目標期的 Nested Walk-forward `profiles.fixed.model_scores` 與 `fusion_weights`；不是用現在的模型倒測舊期。程式檢查每一折訓練／特徵截止期都早於目標。
- 每期先凍結九組完整 80 號分數、排名、候選、歷史範圍、引擎來源雜湊及關聯證據，才讀取該期答案計算命中。目標日期依 `next_draw` 已知排程決定，跨夜第一期不把前一日資料當成今日資料。
- **所有候選視窗共用發現、選擇驗證、最終確認的目標邊界。** 每條規則均另以回放檢查各段範圍，禁止短視窗選擇段與長視窗確認段重疊。視窗選擇不使用最終確認段。
- 除了保留規則，每次實際搜尋的假設也納入 Bonferroni 門檻。每階段須至少 20 次觸發；探索性規則不會以「已驗證」身分貢獻 C 的預測規則權重。
- `lift` 使用平滑估計：`((成功數 + 8 × 隨機基準) / (觸發數 + 8)) / 隨機基準`，與原始條件出現率不同。延遲條件以公平獨立開獎的 20／80 作基準，同期單號共現使用 19／79；多號後件使用不放回超幾何機率。檢查採二項近似與 Wilson 區間，假設仍有適用限制，並非投注獲利證明。

## 重現與完整證據

```bash
python scripts/benchmark_associations.py \
  --nested-directory work/stage2/adaptive \
  --output work/stage2/associations
python -m pytest tests/test_bingo_association_vectorization.py -q
```

輸入 Nested 報告須為相同官方快照產生的真實逐期八模型結果。檔案位於 `validation/stage2/associations/`；gzip JSONL 每行包含一個凍結決策、九組完整分數與各自結果。每份摘要提供來源 Nested 檔案雜湊、引擎來源 SHA-256 及決策鏈雜湊。三份最終報告均使用相同 `bingo-associations-2` 原始碼，初期不完整／舊分段實驗未當作最終證據提交。
