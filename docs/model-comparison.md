# 實際官方資料嚴格 Walk-forward 模型比較

此報告為歷史樣本外模擬，與正式事前封存實戰紀錄完全分開。沒有任何模型或投票方法通過目前的保守優勢檢查。

- 來源：官方 BingoResult API，TLS 憑證驗證開啟。
- 快照：2026-10-28～2026-11-03，1276 期；查詢當日僅包含當時已開獎資料。
- 快照 SHA-256：`a24c78b8a912e815574f053e8f5cda4d5959564bb86a93a8952010f3a4d7aa7f`。
- 每個目標期只使用較早資料；頻率／CDM 隨資料刷新，River 開獎後增量學習，耗資源模型每 100 個回測目標期重新從當時過去資料訓練。
- 回測訓練視窗最多 1000 期；每個目標期至少保留 100 期暖機。各方法的權重僅使用先前已結算折數。
- 八個模型：Frequency、CDM、River、LightGBM、CatBoost、Transformer、DQN、Ensemble，全部實際訓練、評分並參與比較。
- 執行環境：Python 3.12、CPU、每工作程序 2 執行緒；與其他驗證工作共用主機，耗時不能視為硬體服務保證。
